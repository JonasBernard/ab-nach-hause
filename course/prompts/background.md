This is a course in the Mathe-At-Home project. I will lead this course and you will help me working out some of the course material, especially boilerplate code for coding exercises.
All student materials will be in german, except code and code documentation. Agentic work, prompting and so on will be in english.

ab-nach-hause is course for students from 11th grade onwards about an application of mathematics to the real world. In this course, we look at navigation apps and how Dijkstra and A* can be applied to map data using python and open street maps. It consists of 10 weekly meetings online, 90 minutes each. We start on Tuesday, 6 Oct 2026. 3 Nov will be dropped and appended at the end. The readme gives a rough time schedule.
The folder course/ will contain all material that is not for use by the students directly.
Each student will work on a fork of the repository in a GitHub Codespace. The course/ folder can be treated as a transparent internal folder where presentations, exercises, course plan, agentic background information and so on will be placed.
